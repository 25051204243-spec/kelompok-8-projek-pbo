Supermarket Cashier Simulator adalah game simulasi 2D berbasis time-management menggunakan Pygame, di mana pemain mengelola transaksi kasir melalui alur (game states) yang dinamis. Permainan dimulai dari fase SHOPPING untuk menggerakkan pembeli mengambil barang menggunakan tombol WASD/Panah dan tombol 'E'. Setelah menuju meja kasir, permainan beralih ke fase simulator untuk memindahkan barang ke scanner, menginput harga di kalkulator digital, memilih metode pembayaran (Tunai/Non-Tunai), hingga menyerahkan struk belanja. Setiap pelanggan memiliki batas waktu pelayanan 60 detik; jika terlambat mereka akan kabur (menambah skor "Kecewa"), namun jika berhasil, saldo KAS TOKO akan langsung bertambah.
Secara teknis, game ini mengimplementasikan empat pilar Pemrograman Berorientasi Objek (PBO) secara penuh. Pilar Abstraksi dan Polimorfisme diterapkan pada fungsi hitung_transaksi() di kelas induk MetodePembayaran beserta turunannya (BayarTunai dan BayarNonTunai). Pilar Pewarisan (Inheritance) digunakan untuk menurunkan properti objek dari kelas ObjekStatis ke RakBarang. Terakhir, pilar Enkapsulasi diterapkan secara ketat dengan mengunci data keranjang belanja dan keuangan toko menjadi atribut private, yang hanya bisa diakses via fungsi getter dan setter murni sebagai validasi data untuk mencegah error.
